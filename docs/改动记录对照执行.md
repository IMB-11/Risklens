3. `backend/engine/financial_action_trainer.py` 兼容清理：  
   - `finbert-tone` 物理路径已移除后，`finbert` 别名自动回退到 `financial_sentiment` 路径；  
    - 默认仅启用 `financial_sentiment`，并避免同路径模型重复加载。  

4. 决策边界收敛：  
   - Qwen 仅用于协调与解释，不参与风险分和动作决策。  
   - `risk_sklearn` 默认仅旁路参考（shadow），不覆盖主决策；如需覆盖需显式开启 `ENABLE_RISK_SKLEARN_DECISION_OVERRIDE=true`。
